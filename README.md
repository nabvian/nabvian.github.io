# nabvian.github.io

**▶ https://nabvian.github.io/**

One page that links every live project demo and showcase by Koushik Das. Each demo opens in
the browser with no sign-up and no install, pre-loaded with synthetic or
recorded data.

The thumbnails in `img/` are screenshots of each demo, in light and dark.

All patients, documents and models in these demos are synthetic or fictional.
The clinical projects are unvalidated research prototypes and provide no
diagnosis or treatment advice.

`projects/` holds showcase pages for private work: architecture, screenshots and
recorded results only, never code. `projects/showcase.css` is their shared style.
