PATHEX 8000-Case Test Run

Every case below was sent through PATHEX exactly as a laboratory system would send it. The table shows the values PATHEX received and the answer it gave, including when it refused to answer.

Run 27 Nov 2026 Status research prototype, not clinically validated, not a medical device

These are test cases, not patients

All 8,000 cases are generated by a fixed program so that the same set comes out every time. They check how PATHEX behaves across textbook patterns and across unsafe or impossible input. They do not measure accuracy against real diagnoses; that will come from the planned clinical evaluation.

How the cases were made

  • Cases 1 to 4,000, stress set. Values spread across and beyond what is possible, wrong or missing units, empty fields, ages from 0 to 120, sex sometimes missing. PATHEX is expected to refuse most of these and still flag any critical value.
  • Cases 4,001 to 8,000, realistic set. Adults 18 to 85. Five patterns drawn around textbook values with random variation: iron deficiency, beta-thalassaemia trait, macrocytic anaemia with low B12, normal count, and borderline.
  • Women without a pregnancy status are refused. Pregnancy changes the limits for haemoglobin, MCV, ferritin, B12, white count, platelets and TSH, so PATHEX does not read a woman's count with non-pregnant limits unless she is stated not pregnant. None of these generated cases carry a pregnancy status.
  • The generator draws each red-cell index on its own, so some realistic cases have indices that cannot occur together (for example MCV 78 fL with MCH 30.3 pg). PATHEX holds those for verification, as it should.
